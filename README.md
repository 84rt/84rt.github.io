# 84rt.github.io

Personal website of Bart Jaworski, served at [bartjaworski.com](https://bartjaworski.com) via GitHub Pages.

A single static page — no build step, no JavaScript, no dependencies. All writing lives on [Substack](https://substack.com/@84rt).

## Development

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.
